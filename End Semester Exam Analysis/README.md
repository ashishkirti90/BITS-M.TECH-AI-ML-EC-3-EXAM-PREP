## How to use this repository

- Follow the master plan by date rather than reading every file from top to bottom.
- Study a topic from its guide, solve the linked actual PYQs, and record mistakes.
- Memorize core formulas and use the subject watermark index for fast verification.
- Watermark page references use PDF viewer numbering, not printed slide numbering.
- Keep each subject isolated. Do not use one subject's trends to predict another subject.

The supplied course handouts control exam dates, duration, scope, and permitted materials. Confirm any later official BITS notice before the examination.
